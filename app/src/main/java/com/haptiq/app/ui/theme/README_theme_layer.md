## One thing to double check on your end

`Type.kt` uses `androidx.compose.ui.text.googlefonts.Font` with a
`GoogleFont.Provider` pointing at `R.array.com_google_android_gms_fonts_certs`
— that array resource has to exist in your `res/values/` (it's normally
generated by the Google Fonts Gradle plugin or added manually per the
Google Fonts Compose setup guide). If it's not there yet, `Type.kt` won't
compile. Worth confirming before handing this off, since it's the one
external dependency in the theme layer that isn't self-contained.
